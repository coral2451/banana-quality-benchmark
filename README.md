# Banana quality classification: a reproducible benchmark of nine classifiers

Code and results for:

> Chi, J., \& Nindo, C. (in review). Machine learning approaches for banana quality prediction: A reproducible comparative benchmark.

The study compares nine classifier configurations (LDA, logistic regression, two decision trees, KNN, Gaussian naive Bayes, a multilayer perceptron, random forest, and an RBF support vector machine) on the Banana Quality dataset (8,000 records, seven attributes, Good/Bad label). Hyperparameters are tuned on the training set only, the test set is used once, and classifiers are compared with McNemar's test and corrected resampled t-tests.

## How to run

```bash
pip install -r requirements.txt
bash run\_all.sh path/to/banana\_quality.csv     # or the .xlsx
```

Or run the steps one at a time in the order shown in `run\_all.sh`. All scripts use fixed random seeds (`random\_state = 42`), and `results/split\_and\_folds.csv` records which rows were in the training and test sets and the cross-validation fold of each training row.

## Software

Results were produced with Python 3.13, scikit-learn 1.9.1, NumPy 2.5.3, pandas 3.0.5, SciPy 1.18.1 and Matplotlib 3.11.2 (`requirements.txt`). Other versions should give very similar results, but the last decimal places may differ.
